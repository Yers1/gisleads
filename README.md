# gisleads

Лиды из 2GIS: малый бизнес без сайта / без WhatsApp-Telegram.
Для веб-студий и фрилансеров, которые продают сайты и ботов локальному бизнесу.

## Запуск

```
python leads.py "Алматы" "салон красоты" --key ВАШ_КЛЮЧ --pages 5
```

Ключ бесплатно: https://dev.2gis.com (или переменная окружения `GIS_KEY`).

## Что делает

Поиск по городу + рубрике → телефоны, сайты, соцсети → метки `needs_site` / `needs_bot` → скоринг → `leads.csv` (открывается в Excel, кириллица не ломается).

## Самопроверка

```
python leads.py --demo
```
